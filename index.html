คำชี้แจงการเล่น

  1. กรอกชื่อ-นามสกุล เลขประจำตัวนักศึกษา ชั้น/กลุ่มเรียน และแผนกวิชาให้ครบถ้วน
  2. เลือกโหมดและ Level ที่ต้องการ โดย Classic เป็นโหมดมาตรฐาน
  3. ระบบจะเริ่มจับเวลาทันทีเมื่อเริ่มพิมพ์ Code
  4. ตัวอักษรที่ถูกจะแสดงเป็นปกติ ตัวที่ผิดจะแสดงสีแดง และระบบนับ Mistakes
  5. คะแนนคำนวณจากความยากของ Level, ความเร็ว, Accuracy และจำนวนครั้งที่พิมพ์ผิด
  6. Speed Rush และ Hardcore มีเวลาจำกัด เมื่อหมดเวลาระบบจะจบรอบอัตโนมัติ
  7. Hardcore ไม่อนุญาตให้ใช้ Backspace/Delete
  8. เมื่อพิมพ์ Code ถูกต้องครบ 100% ระบบจะบันทึกผลลง Firebase Firestore
