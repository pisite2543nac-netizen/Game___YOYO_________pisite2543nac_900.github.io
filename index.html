เกมพิมพ์ Code 12 Level 4 โหมด จับเวลา + WPM

คำชี้แจงการเล่น

  1. โจทย์ Code จะถูกจัดตาม Level จากง่ายไปยาก ครอบคลุม HTML, CSS, JavaScript, Python และ Flask
  2. คะแนนของแต่ละ Level ไม่เท่ากัน โดยคิดจากคะแนนฐาน ความยาก ความเร็ว ความแม่นยำ และจำนวนครั้งที่พิมพ์ผิด
  3. ก่อนเข้าสู่ระบบเกมต้องลงทะเบียนให้ครบถ้วน ได้แก่ ชื่อ-นามสกุล ชั้น/กลุ่มเรียน แผนกวิชา และเลขประจำตัวนักศึกษา
  4. เมื่อลงทะเบียนสำเร็จ ระบบจะเข้าสู่หน้า User เพื่อเลือกโหมดเกมและ Level ก่อนเริ่มเล่น
  5. Classic เป็นโหมดมาตรฐาน ส่วน Speed Rush, Accuracy Pro และ Hardcore มีกติกาและตัวคูณคะแนนแตกต่างกัน
  6. ระบบเริ่มจับเวลาเมื่อผู้เล่นเริ่มพิมพ์ และบันทึก WPM, Accuracy, Mistakes และเวลาเล่น
  7. ในโหมดที่จำกัดเวลา เมื่อหมดเวลาระบบจะยุติรอบและบันทึกสถานะอัตโนมัติ
  8. Hardcore ไม่อนุญาตให้ใช้ Backspace หรือ Delete
  9. ผลการเล่นจะถูกบันทึกลง Firebase Firestore กลาง และผู้ดูแลระบบสามารถตรวจสอบได้จากหน้า Admin
  10. ผู้เล่นควรพิมพ์ด้วยตนเอง และไม่แก้ไข Source Code ของหน้าเว็บระหว่างเล่น
